# kabangoura.github.io

Page d'accueil de l'adresse `https://kabangoura.github.io/`.

Elle donne à Google l'icône (bouclier) et le nom **KMB Library** pour ce domaine, et mène vers :
- [KMB Library](https://kabangoura.github.io/detection-des-failles-de-securite/)
- [le portfolio](https://kabangoura.github.io/portfolio/)

Ce dépôt ne contient que cette page : les autres sites (`/portfolio/`, `/detection-des-failles-de-securite/`) restent servis par leurs propres dépôts.
Pour revenir à la situation d'avant, il suffit de supprimer ce dépôt ; pour donner une autre icône au domaine, il suffit de remplacer les fichiers `favicon.*` et `icon-*.png`.
